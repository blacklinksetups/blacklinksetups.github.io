Anoneurx Blacklink

Turn any Linux box into a managed host.

Blacklink installs the Anoneurx Connect agent and wires the host to the console with end-to-end-encrypted tunnels, RBAC, firewall, filesystem access, logs and a live terminal.

Install (one line)
curl -fsSL https://blacklink.anoneurx.com/bash | sudo bash
01

Install & enroll

The signed agent lands at /usr/local/bin/anoneurx-connect (alias blacklink), runs as a locked-down systemd service, and enrolls its Ed25519 identity with your gateway.

02

Create your login

Run blacklink setup once to set a username and password. It is argon2-hashed and stored 0600 on the host — never in the cloud.

03

Sign in from the console

Open the Anoneurx dashboard, pick the host, and sign in with its IP, username and password. The console verifies credentials before it ever mints a session.
